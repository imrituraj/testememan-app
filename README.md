# TestMeMan Secure Assessment Clients

Official desktop lockdown and proctored examination clients for the [TestMeMan](https://testmeman.in) platform.

This repository contains the native safe-exam lockdown applications used for corporate online assessments (OAs), campus hiring drives, and proctored tests.

## Applications

- **[mac-app/](./mac-app)**: Native macOS assessment client built with Electron, featuring workspace security lockdown, process manager, shortcut blocking, and camera proctoring.
- **[windows-app/](./windows-app)**: Windows assessment client built with Electron, featuring Windows kiosk lockdown, task switching prevention, and camera monitoring.

## Features

- **Zero-Distraction Environment**: Locked full-screen mode preventing tab switching, unauthorized apps, and unauthorized shortcuts.
- **Integrity & Anti-Cheat Engine**: Real-time process monitoring, multiple display detection, and AI camera face tracking.
- **Cloud-Synced CBT Runner**: Offline session recovery, live countdown timers, and instant verified integrity receipts.
- **Official TestMeMan Brand Integration**: Native retina app icons, brand lockup, and dark hacker-glass assessment UI.
